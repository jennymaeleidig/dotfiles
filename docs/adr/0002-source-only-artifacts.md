# Source-only artifacts never reach a host

Repo docs (`README.md`, `CONTEXT.md`, `AGENTS.md`, `CODING_STANDARDS.md`), `docs/`, `tools/`, and `.scratch/` live in the repo — the source of truth for setup knowledge and provisioning material — but `.chezmoiignore` keeps them out of target state: a host only receives dotfiles, templates, and scripts. The alternative (applying everything) would pollute the home directory with repo docs and tool sources; keeping them outside the repo would fragment the source of truth. Source-only artifacts are enumerated explicitly in `.chezmoiignore` (a blanket `*.md` rule is forbidden — it would swallow the opencode app config's markdown commands and skills). The ignore list is the enforcement of this boundary, so new source-only artifacts must be added there explicitly.

`.chezmoiignore` has a second purpose: it also enumerates runtime state — files running programs write on a host or in the source directory that this repo deliberately does not manage. Ignore entries are therefore not all source-only artifacts; classify each new entry before adding it.
