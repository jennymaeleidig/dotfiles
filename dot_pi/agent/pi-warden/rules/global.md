# New code cites no record

An added comment, doc line, test name, or symbol name that cites a specific point-in-time record — an ADR (`ADR-0002`), a ticket, a spec, a plan, a wayfinder map, a research note — as the reason for the change. A citation that was already there before the edit is not this edit's. A path placeholder defining the convention (`.scratch/<feature-slug>/spec.md`), a bare generic filename (`spec.md`, `map.md`), and an ignore-list entry are conventions, not citations. Tracker documents under `.scratch/` are exempt: citing specs, tickets, and maps is what they are for.
